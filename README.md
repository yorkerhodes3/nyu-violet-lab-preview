# Violet / Lab

An unofficial, independent design concept for a cross-NYU build weekend. The preview is meant to answer two early questions:

1. What would participation feel like?
2. What kinds of projects could someone create, join, or advise?

- **[Open the editorial concept](https://yorkerhodes3.github.io/nyu-violet-lab-preview/)** — an expressive orientation and project-discovery experience
- **[Open the portal-style concept](https://yorkerhodes3.github.io/nyu-violet-lab-preview/studio/)** — a closer interpretation of the supplied enterprise hackathon layouts

## Privacy and provenance

- Every project, challenge, person, role, metric, date, and team shown in the site is synthetic.
- Public NYU school names are used only to make the cross-school concept understandable.
- No internal project names, participant identities, screenshots, or source text are published.
- This project is not sponsored, reviewed, or endorsed by New York University.

## Run locally

The preview is a dependency-free static site:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Interactions included

- Search, sort, and filter fictional projects
- Browse six synthetic challenge areas
- Open project detail drawers
- Save projects locally in the browser
- Try a short participation matcher
- Preview project-creator and advisor guidance
- Compare an editorial concept with a portal-style enterprise concept
